#+AUTHOR: Daniel Muñoz
#+TITLE: org-blogger

~org-blogger~ publishes [[https://orgmode.org/][Org mode]] documents to
[[https://www.blogger.com/][Blogger]]. It exports each Org file to HTML with Emacs, reads the
title and tags from the document metadata, and creates the post through the
Blogger API.

It is language-agnostic: the content is exported by Emacs, so posts can be
written in English, Spanish, or any other language.

* Requirements

+ Python >= 3.11
+ [[https://docs.astral.sh/uv/][uv]] (recommended) or ~pipx~
+ Emacs with ~org-html-export-to-html~ available in batch mode
+ A Google Cloud project with the Blogger API enabled

* Installation

#+begin_src shell
uv tool install git+https://github.com/koprotk/org-blogger.git
#+end_src

Or install it from a local clone:

#+begin_src shell
git clone https://github.com/koprotk/org-blogger.git
cd org-blogger
uv sync
uv tool install .
#+end_src

* Google credentials

1. Create an OAuth client of type *Desktop app* in the
   [[https://console.cloud.google.com/][Google Cloud Console]] and enable the Blogger API.
2. Download the client secret JSON file. Its name starts with
   ~client_secret~ and ends with ~.json~.
3. Place it in a configuration directory:
   - ~~/.config/org-blogger/~ (recommended, outside any repository), or
   - ~./config/~ inside the directory where you run the command.

The first run opens a browser to authorize the application and writes
~token.json~ next to the client secret. Keep both files private and never
commit them.

The configuration directory can also be set with
~ORG_BLOGGER_CONFIG_DIR~ or with ~--config-dir~.

* Usage

From the root of your blog repository:

#+begin_src shell
org-blogger publish drafts/my-post.org
#+end_src

By default the command:

1. resolves ~my-post.org~ inside ~./drafts~,
2. exports it to HTML with Emacs,
3. reads ~#+TITLE~ and ~#+TAGS~,
4. publishes it to the first blog of the authenticated account,
5. moves the Org file to ~./posts~.

A complete, copyable example post is included in
[[file:drafts/example.org][drafts/example.org]].

Useful options:

#+begin_src shell
org-blogger publish drafts/my-post.org \
  --drafts-dir drafts \
  --posts-dir posts \
  --config-dir ~/.config/org-blogger \
  --blog-id 1234567890 \
  --draft
#+end_src

+ ~--draft~ creates the post as a draft instead of publishing it immediately.
+ ~--blog-id~ skips the lookup of the first blog.
+ ~--config-dir~ overrides the credential directory.
+ ~--drafts-dir~ and ~--posts-dir~ make the tool usable from any layout.

The old ~publish-blog my-post.org~ command still works as an alias of
~org-blogger publish~.

* Metadata

#+begin_src org
#+TITLE: My post title
#+TAGS: emacs, org, blogger
#+end_src

Tags can be separated by commas or whitespace. If ~#+TAGS~ is absent, the post
is published without labels.

** Front image

Link an image with an image extension in the body of the post:

#+begin_src org
[[https://example.com/image.png]]
#+end_src

* Development

#+begin_src shell
git clone https://github.com/koprotk/org-blogger.git
cd org-blogger
uv sync
uv run python -m unittest discover -s tests -v
#+end_src

Run the CLI from the checkout with:

#+begin_src shell
uv run org-blogger publish /path/to/post.org --config-dir ~/.config/org-blogger
#+end_src
